# ENSO 六款商品圖片目錄

日期：2026-09-30

已完成六款商品共三十張獨立概念圖，每款一張主圖、四張圖庫。系列方向已確認，個別圖片仍待選用，尚未上傳、替換商品資料或部署。

已另存[網頁壓縮版本與預覽](WEB-IMAGES.md)，包含完整圖、中圖及縮圖共九十張 WebP。三十張完整圖約 5.77 MiB，比本頁 PNG 原稿減少 91.14％。原稿不變，仍未上架。

目前已接入本機後台展示模式，六款各有主圖及四張圖庫，正式 API 與線上商品資料未更動。展示接入不代表真實商品或個別圖片的商業使用核准。

## 素材規格

- 三十張 PNG，實際尺寸皆為 1122 × 1402 像素，接近四比五直式。
- 原稿合計約 65.2 MiB，不應一次載入全部圖片作為正式商品頁。
- 每張圖片有獨立提示詞文字檔，亦保存於 PNG 文字中繼資料。
- [完整素材對應清單](manifest.json)記錄用途、替代文字、尺寸、校驗碼及預計欄位。
- 前台既有圖檔與商品圖片 URL 均保留，不覆蓋 Golden Hour 原圖。

## 使用前注意

這些是生成式概念圖，不是真實商品實拍。英文名稱、盒型、紙材、線香及配件比例是視覺提案，不能據此宣稱實際規格。圖中的植物、花朵、書籍與香具是情境道具，不代表配方或購買內容。

主圖及情境圖可先供作品展示選用。細節圖為刻意近拍，不適合充當完整包裝主圖。材質圖目前偏向線香與包裝的情境展示，若需要精準微距材質資訊，應使用經核對的素材。不同圖中包裝比例及紋理仍可能有細微差異，商業使用前需與真實商品核對。

## 預計上架方式

一款商品的主圖對應 imageUrl。imagesUrl 依序為包裝細節、生活情境、材質情境、比例與使用情境，共四張，保留第五格。

壓縮網頁版本已另存。先確認單張圖片與實際品項，再上傳並取得公開圖片網址。不要把本機檔案路徑直接填入 API，也不要清除原圖片網址。比例圖不提供尺寸數據，不可作為尺寸保證。
