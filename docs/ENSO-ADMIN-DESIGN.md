# ENSO 後台設計系統

## 定位

ENSO 後台是營運工作台，不是前台行銷頁。視覺延續 ENSO 品牌，但資訊層級、狀態提示與操作效率優先。

## 色彩

| Token | 色彩 | 用途 |
| --- | --- | --- |
| `--enso-cream` | `#efe6e1` | 工作區背景 |
| `--enso-surface` | `#fffaf6` | 卡片、表單與表格背景 |
| `--enso-blue` | `#09256f` | 主要文字、標題、導覽 |
| `--enso-lime` | `#d9f81b` | 選取導覽、示範操作強調 |
| `--enso-orange` | `#ff5a1f` | 強調、提醒與重要操作 |
| `--enso-ink-muted` | `#53607a` | 輔助文字 |
| `--enso-line` | `rgba(9, 37, 111, 0.16)` | 分隔線與輸入框 |

## 元件規則

- 導覽使用「總覽、商品、訂單、庫存、優惠券、金流、設備」等直白用語。
- 表格在窄螢幕以容器內水平捲動，不讓整個頁面產生水平溢位。
- 商品主圖及圖庫預覽以固定容器搭配 `object-fit: contain`，避免裁切包裝。情境圖可另外使用 cover，但不得沿用至商品縮圖。
- 狀態不可只用顏色表示，必須同時有文字。
- 表單欄位使用 8px 圓角，容器使用 12px 圓角，彈窗使用 16px 圓角，小型控制項使用膠囊形。
- 主要提交按鈕使用深藍底與淺色文字，刪除操作使用紅色語意。
- 後台不使用前台展示用的大型裝飾字體作為資料或控制項文字。

## 響應式斷點

- 390px：單欄、折疊導覽，商品改為卡片，訂單、庫存與優惠券保留容器內捲動表格。
- 768px：雙欄摘要、容器內表格捲動。
- 1024px：完整導覽與兩欄工作區。
- 1440px：限制內容最大寬度，保留舒適掃讀距離。
