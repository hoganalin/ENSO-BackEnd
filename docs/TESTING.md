## 基本命令

```sh
npm run lint
npm test
npm run build
npm run preview
```

`npm test` 使用 Node.js test runner，`npm run verify` 依序執行 lint、單元測試及建置。`npm run test:browser` 執行專案內 Playwright 測試，`npm run test:all` 執行以上兩套檢查。尚未建立持續整合測試工作流程，不能將本機結果解讀為正式 API 端到端測試已通過。

首次使用請執行 `npm ci` 及 `npx playwright install chromium`。瀏覽器測試自動建置至 `.browser-build/` 並啟動 4176 連接埠，結束時由測試工具停止該預覽服務，不使用正在開發的 5174 站台，不覆蓋 `dist/`。若 4176 已被其他服務占用，測試會停止，請先查明服務用途，不要直接終止不明程序。

`tests/browser/admin.spec.js` 收錄六個案例，分別在 1440 與 390 寬度執行，共十二項。涵蓋登入拒絕、連線失敗、Cookie 期限、驗證重試、商品 API 讀寫失敗、圖片預覽、焦點、售價與圖庫持久化。每個案例建立獨立瀏覽器資料，所有 API 回應由攔截器提供，外部請求一律阻擋。

報告及失敗截圖／追蹤檔保存在忽略的 playwright-report、test-results；檢視命令為 `npx playwright show-report`。舊版 .impeccable/review 測試是歷史本機紀錄，不要求其他開發者安裝該目錄或使用個人電腦路徑。

## 操作驗收

- 登入：欄位驗證、展示入口、保持登入、登出。
- 商品：新增、修改價格、刪除、重新整理後仍維持結果。
- 圖片：主圖網址、失敗 fallback、更換 URL 恢復、格式／大小限制、示範上傳、五張圖庫上限、移除及保存。
- 訂單：收件資訊、數量正整數驗證、合計、付款標記、刪除確認。
- 庫存：增加／扣減、拒絕小數及超額扣減、最近五筆本機紀錄。
- 優惠券：名稱／代碼必填、日期、1 至 100 的折後比例、啟用。
- 設備：本機設定重新整理保存、示範資料下載、模擬校準說明。
- 金流：未提供付款方式的訂單不被補上假資料，部分請求失敗有提醒。
- 空資料、錯誤、載入及成功通知皆可辨識。
- native dialog：Tab 焦點不離開對話框，Escape 關閉，儲存中不可重複提交。
