# 後台功能

## 完整面試展示

storefront 購物副本已串接自建資料庫 API，支援搜尋、分類、主圖與圖庫、購物車增減刪除、預填展示收件資料、建立未付款訂單、送單失敗原單重試與價格異動確認。後台取消未付款訂單會回補庫存，商品調價與下架可反映到前台。設備仍為模擬，付款標記不等於收款。

以 build:showcase 建置並啟動 showcase 入口後，使用 PostgreSQL 隔離空間，而非下述舊 localStorage 預覽模式。圖片上傳實際保存於該空間的資料庫，原始圖片資產不覆寫。詳見 [展示指南](INTERVIEW-DEMO.md)。

## 登入與資料來源

管理員使用既有登入 API，Token 存入 Cookie。勾選「保持登入」時使用 API 回傳期限，未勾選則使用工作階段 Cookie。展示入口使用專用 demo token，CRUD 由 demoStore 攔截並保存在 localStorage，不會修改正式 API 資料。

## 商品

- 分頁、當頁名稱或分類搜尋、已上架／未上架篩選。
- 新增、修改與刪除使用相同 native dialog，支援 Escape、焦點限制及返回原操作按鈕。
- 保留原欄位，包括名稱、分類、價格、單位、庫存、描述、內容、特色、三段香調與三個使用情境。
- 主圖支援網址及檔案上傳，圖庫最多五張網址，每張可預覽或移除。
- 圖片載入失敗後可更換網址，不需關閉編輯視窗。
- 上傳介面限制 JPG／PNG／WebP、3 MB。展示模式回傳示範圖，不儲存實際檔案。

## 訂單

當頁搜尋訂單編號／收件人，依付款狀態篩選。詳情可以修改收件人姓名、電話、地址、電子郵件及商品數量。自建後端依價格快照與原折扣計算總額，已付款不可改數量或取消。未付款訂單取消會回補庫存並保留資料，不提供全部清空。展示模式維持原本刪除流程。付款標記不代表執行收款或退款。

## 庫存

以商品 inventory 欄位儲存數量。低於十件且大於零為低庫存，零件為缺貨。調整只接受正整數，扣減超過庫存時拒絕提交。自建後端保存異動管理員、原因與前後數量，視窗讀取伺服器最近五筆。展示模式以 localStorage 保存最新二百筆，不是伺服器稽核紀錄。

## 優惠券

新增、修改及刪除活動名稱、折扣碼、到期日、折後應付比例與啟用狀態。比例填 80 代表支付原價的百分之八十，不是折抵百分之八十。到期與停用狀態會以文字顯示。

## 總覽與金流

總覽從商品、訂單 API 第一頁計算本頁營收、平均客單價、付款比例、銷售趨勢與熱門商品。待辦使用未付款訂單與低庫存商品，不讀取舊版候選事件服務。

金流頁最多讀取十頁訂單，只使用來源已提供的付款方式，不為缺少資料的訂單推測付款方式。模擬資料不是銀行對帳或真實收款證明。

## 設備

前端示範設備狀態。設定寫入 enso_device_overrides，匯出依選定條件產生示範 CSV／JSON／TSV。校準為模擬互動，沒有向硬體送指令。頁面明確標示未連接實體設備。

## 共用介面

桌機導覽橫跨視窗，內容保有最大寬度。860px 以下採折疊導覽。商品在 768px 以下採卡片，其餘表格保留容器內水平捲動。通知提供關閉按鈕並自動消失。

/admin/agent 仍導回 /admin，沒有公開入口。
